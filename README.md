## 1. Назначение и цели Цифрового Советчика

**Цифровой Советчик смесительно-прессового отделения (СПО)** предназначен для исследования, поиска идеальных рецептур шихты и оптимизации режимов производства анодной массы для алюминиевых электролизеров Содерберга (ВТ — боковой и верхний токоподвод).

### Ключевые технологические задачи:
1. **Автоматический расчет оптимальной потребности шихты в пековом связующем ($W_{пек\_opt}$)** с точностью до **0,1%** на основе гранулометрии 4-х фракций кокса, пористости зерна и удельной поверхности пылевой фракции.
2. **Поддержка двух технологических режимов выпуска массы по схеме**:
   - **Основная анодная масса**: базовое целевое содержание пека **28,0%** (текучесть по Эйхлеру $F_I = 1,6 \dots 2,8$).
   - **Подштыревая анодная масса**: базовое целевое содержание пека **31,0%** (+3,0% пека для надежного заполнения подштыревых лунок).
3. **Достижение целевого удельного электрического сопротивления (УЭС) $RES \le 62,0\text{ мкОм·м}$** (снижение со 72 до 62 мкОм·м дает экономию ~150 кВт·ч э/э на тонну алюминия).
4. **Контроль виброобъемной плотности кокса ($\text{ВОП} \ge 0,82\text{ г/см}^3$)** и предотвращение "угольного шума" (осыпаемости).
5. **Интерактивная верификация и корректировка уравнений** с возможностью изменения эмпирических коэффициентов и просмотра первоисточников (ISO, TMS Light Metals, US EPA).

## 2. Физико-математическая модель процесса

Модель описывает цепочку от прокалки сырого кокса до спекания анодного блока в электролизере:

1. **Кривая упаковочной плотности Фуллера ($P(d)$)**:
   $$P(d) = 100 \times \left(\frac{d}{D_{\max}}\right)^{0.33}$$
   Рассчитывается на 4-х фракционных чекпоинтах: пыль ($< d_{dust}$), мелкая ($d_{dust} \dots dC2Min$), средняя ($dC2Min \dots dC1Min$), крупная ($dC1Min \dots dC1Max$).

2. **Удельная поверхность пылевой фракции ($S_{sp}$, см²/г)**:
   $$S_{sp} = 3200 \times \left(\frac{\text{ДоляПыли}}{36}\right) \times \left(\frac{0.071}{d_{dust}}\right)\text{ см}^2/\text{г}$$

3. **Оптимальная потребность в пековом связующем ($W_{пек\_opt}$, wt %)**:
   $$W_{пек\_opt} = \text{БазаПека} + k_{surface}(S_{sp} - 3200) + k_{density}(2.08 - \rho_{real}) + k_{porosity}(\text{Пористость} - 21.0) - k_{butt}\text{Огарок} - k_{coking}(\text{КоксПека} - 57.5) - k_{softening}(\text{КиШ} - 103)$$

4. **Текучесть анодной массы по Эйхлеру при 150 °C ($F_I$)**:
   $$F_I = F_{base} + k_{pitch} \cdot \text{ДельтаПека} + k_{temp} \cdot \text{ДельтаТемпературы} - k_{\alpha} \cdot (\text{Альфа} - 9.5)$$

5. **Кажущаяся плотность обоженного анода ($\rho_{baked}$, г/см³)**:
   $$\rho_{baked} = \rho_{base} - k_{pitchDelta} \cdot |\text{ДельтаПека}| - k_{packing} \cdot (100 - \text{УпаковкаФуллера}) - k_{ash} \cdot \text{ЗольностьКокса}$$

6. **Удельное электрическое сопротивление ($RES$, мкОм·м)**:
   $$RES = RES_{base} + k_{density} \cdot (1.52 - \rho_{baked}) + k_{pitchDelta} \cdot |\text{ДельтаПека}| + k_{ash} \cdot \text{ЗольностьКокса} \le 62.0\text{ мкОм·м}$$

7. **Предел прочности на сжатие ($\sigma_{comp}$, МПа)**:
   $$\sigma_{comp} = \sigma_{base} \times \left(\frac{\rho_{baked}}{\rho_{target}}\right)^2 - k_{pitchDelta} \cdot |\text{ДельтаПека}|$$

8. **Осыпаемость в среде $\text{CO}_2$ и $\text{O}_2$ ($Dusting$, % потерь)**:
   $$Dusting = D_{base} + k_{pitchDelta} \cdot |\text{ДельтаПека}| + k_{ash} \cdot \text{ЗольностьКокса}$$

9. **Выхлоп полициклических ароматических углеводородов ($PAH$, кг/т Al)**:
   $$PAH = 0.42 \times (1 + (\text{ТемператураСмесителя} - 160) \times 0.012) \times \left(\frac{W_{пек}}{28.5}\right)$$

## 3. Обзор интерфейса дашборда

Дашборд состоит из 5 логических блоков:

1. **Верхняя панель управления (Header)**:
   - Переключатель режима массы (**Основная 28.0%** / **Подштыревая 31.0%**).
   - Выбор готовых пресетов сырья (Стандартный, Высокопористый кокс, Экоанод, Смесь с огарком и др.).
   - Кнопка **«Редактор формул»** (вызов модального окна настройки коэффициентов).
   - Кнопка **«Источники и отчет»** (генерация акта верификации).

2. **Информационный банер состояния (Alert Banner)**:
   - Отражает текущий статус режима (В НОРМЕ, ВНИМАНИЕ, ОПАСНОСТЬ БРАКА).
   - Сигнализирует о рисках перепекования, недопекования или низкого ВОП кокса ($<0,82$ г/см³).

3. **Левая панель ввода (Входной контроль и Оборудование)**:
   - Блок 1: Прокалочная печь и физико-химические свойства кокса ($\rho_{real}$, ВОП, пористость, зольность, огарок).
   - Блок 2: Каменноугольный пек (температура размягчения КиШ, выход кокса, $\alpha$- и $\beta$-фракции).
   - Блок 3: Раздельная настройка границ 4-х фракций шихты ($dC1Max$, $dC1Min$, $dC2Min$, $dDust$).
   - Блок 4: Слайдеры процентного соотношения 4-х сортовых бункеров (Крупная 1, Крупная 2, Мелкая, Пылевая).
   - Блок 5: Настройки весовых дозаторов ($W_{пек}$ с шагом 0,1%, производительность линии т/ч, погрешности).
   - Блок 6: Температурный режим (подогреватель кокса, жидкий пек, непрерывный смеситель).

4. **Правая панель результатов (Советчик и Прогноз)**:
   - **Карточки рекомендаций Советчика**: Сравнение уставки дозатора пека с оптимальным значением $W_{пек\_opt}$, целевая температура смесителя, шкала плотности упаковки Фуллера.
   - **6 Прогнозных KPI карт**: Текучесть по Эйхлеру, кажущаяся плотность, УЭС, прочность, осыпаемость, выхлоп ПАУ.

5. **Визуализация и Графики**:
   - **2D-визуализатор ванны Содерберга в реальном времени**: Отражает гидродинамическую волну текучести жидкой массы, зону пиролиза (400–600 °C), обоженный анод и токоподводящие штыри.
   - **График упаковочной плотности Фуллера**: Сравнение фактической кумулятивной кривой с идеальной параболой ($q=0,33$).
   - **Реологический график**: Зависимость текучести массы от температуры смесителя в диапазоне 150–215 °C.

## 4. Пошаговая инструкция работы для технолога-исследователя

### Шаг 1: Выбор режима анодной массы
1. В верхней панели выберите **«Режим массы по схеме»**:
   - Если вы исследуете базовый состав анода — выберите **«Основная анодная масса (База 28.0%)»**.
   - Если исследуется состав для подштыревой зоны электролизеров ВТ — выберите **«Подштыревая анодная масса (База 31.0%)»**.

### Шаг 2: Ввод лабораторных показателей сырья
1. Задайте параметры кокса по паспортным данным поставщика:
   - Истинная плотность $\rho_{real}$ (г/см³).
   - Виброобъемная плотность ВОП (если ВОП $< 0,82$, система выведет предупреждение о недопрокалке).
   - Впитываемость пека / Пористость кокса (%).
   - Зольность $A$ (%).
2. Укажите долю возвращаемого анодного огарка (10–30%).
3. Задайте характеристики каменноугольного пека:
   - Температуру размягчения по «Кольцу и Шару» (КиШ, °C).
   - Выход коксового остатка и $\alpha$-фракцию (QI).

### Шаг 3: Настройка гранулометрического состава шихты
1. В карточке **«Настройка границ 4-х фракций рассева»** укажите граничные размеры ячеек сит:
   - $dC1Max$ (верхний размер крупной фракции, по умалч. 10.0 мм).
   - $dC1Min$ (граница между Крупной 1 и Крупной 2, по умалч. 4.0 мм).
   - $dC2Min$ (граница между Крупной 2 и Мелкой, по умалч. 1.0 мм).
   - $dDust$ (граница тонкого помола шаровой мельницы, по умалч. 0.071 мм / 71 мкм).
2. Слайдерами в блоке сортовых бункеров отрегулируйте дозировку фракций так, чтобы их сумма составляла **100%**. При необходимости нажмите кнопку **«Сбалансировать 100%»** для мгновенного пропорционального автовыравнивания суммы долей.
3. Обратите внимание на индикатор **«Плотность упаковки шихты»**: цель — получить значение $\ge 88\%$.

### Шаг 4: Исследование дозирования пека с шагом 0,1%
1. В поле **«Заданная дозировка пека $W_{пек}$»** вводите уставку дозатора с точностью до **0,1%** (например, 28.0%, 28.1%, 28.2%).
2. Наблюдайте в реальном времени, как изменение дозировки пека всего на 0,1% меняет:
   - Текучесть массы по Эйхлеру.
   - Кажущуюся плотность и УЭС обоженного анода.
   - Волновое гидродинамическое движение жидкой массы на 60fps 2D-визуализаторе ванны.
   - Случайный разброс дозирования ($\pm \sigma_W = \sqrt{\delta_{coke}^2 + \delta_{pitch}^2}$ wt %).

### Шаг 5: Корректировка формул и эмпирических коэффициентов
1. Нажмите кнопку **«Редактор формул»** в верхней панели.
2. В выпадающих карточках представлены **9 математических уравнений** модели (включая расчет ВОП и выбросов ПАУ), русскоязычные имена переменных (`БазаПека`, `УдельнаяПоверхностьПыли`, `ДельтаПека` и др.) и поля ввода коэффициентов.
3. Измените любой коэффициент (например, поднимите $k_{surface}$ с 0.0017 до 0.0020) и нажмите **«Применить и Пересчитать»**. Все настройки автоматически сохраняются в локальное хранилище (`localStorage`).
4. Дашборд мгновенно пересчитает все показатели по вашей кастомной формуле!
5. Если требуется вернуть формулу к стандартному виду:
   - Для отдельной формулы: нажмите кнопку **«Восстановить эту формулу»** (или кнопку в модальном окне `?`).
   - Для всех формул сразу: нажмите **«Восстановить ВСЕ формулы»**.

### Шаг 6: Проверка первоисточников и статуса доступа
1. Нажмите иконку **`?`** возле любого изменяемого или измеряемого параметра (всего 38 интерактивных справочников).
2. В окне отобразится:
   - Физический смысл параметра.
   - Математическая формула.
   - Название первоисточника (ISO, ASTM, TMS Light Metals, US EPA).
   - Значок статуса доступа: **🔓 Открытый доступ** или **🔒 Платный доступ (ISO Store / Springer Paywall)**.
   - Прямая кликабельная гиперссылка на первоисточник.
   - **Цитата-фрагмент из оригинала статьи/стандарта**, подтверждающая используемую формулу.

### Шаг 7: Генерация и печать исследовательского акта
1. Нажмите кнопку **«Источники и отчет»** в верхней панели.
2. Сформируется формализованный лабораторно-промышленный акт верификации с таблицей формул, текущими расчетами и полями для подписей технолога и руководителя лаборатории.
3. Нажмите **«Распечатать / Сохранить в PDF»**. Благодаря встроенным `@media print` стилям формируется чистый документ без интерфейсного мусора.

## 5. Справочник переменных модели на русском языке

| Русскоязычная переменная в модели | Переменная в коде | Описание и единицы измерения |
| :--- | :--- | :--- |
| `БазаПека` | `cfgPitch.base` | Базовый расчетный процент пека (28.7% для выхода на 28.0% в стандартном рецепте) |
| `УдельнаяПоверхностьПыли` | `dustSurface` ($S_{sp}$) | Удельная поверхность тонкого помола кокса (см²/г) |
| `ИстиннаяПлотностьКокса` | `cokeRealDensity` ($\rho_{real}$) | Плотность вещественного вещества кокса (г/см³) |
| `ПористостьКокса` | `cokePorosity` | Впитываемость пека порами зерна (%) |
| `ДоляОгарка` | `anodeButtRatio` | Содержание рециклового анодного огарка (%) |
| `ВыходКоксаПека` | `pitchCokingValue` | Коксовый остаток пекового связующего (%) |
| `ТемператураРазмягчения` | `pitchSoftening` | Температура размягчения КиШ (°C) |
| `ДельтаПека` | `pitchDelta` ($\Delta W$) | Отклонение факта пека от оптимального $W_{пек} - W_{пек\_opt}$ (%) |
| `ДельтаТемпературы` | `tempDelta` ($\Delta T$) | Отклонение температуры смесителя от оптимальной (°C) |
| `АльфаФракция` | `pitchAlpha` | Содержание хинолин-нерастворимых веществ QI (%) |
| `ТвердаяСмолаБета` | `pitchBeta` | Смолы $\beta$-фракции (связующая способность) (%) |
| `УпаковкаФуллера` | `packingEfficiency` | Плотность упаковки шихты по кривой Фуллера-Андреасена (%) |
| `ЗольностьКокса` | `cokeAsh` ($A$) | Содержание минеральных примесей в коксе (%) |
| `ПлотностьОбоженного` | `bakedDensity` ($\rho_{baked}$) | Кажущаяся плотность обоженного анода (г/см³) |
| `РазбросДозирования` | `dosingScatter` ($\sigma_W$) | Случайная погрешность дозирования ($\pm \sqrt{\delta_c^2 + \delta_p^2}$, wt %) |

## 6. Онлайн-запуск, тестирование и локальное развертывание

### Онлайн-запуск без установки (GitHub Pages):
Перейдите по ссылке: 👉 **[https://AnanyevMA.github.io/PEK/](https://AnanyevMA.github.io/PEK/)**

### Автоматическое тестирование:
В проект встроен автоматический набор тестов `test_engine.js` (запускается через GitHub Actions при каждом push в `main`):
```bash
node test_engine.js
```
Тесты проверяют:
- Корректность физических диапазонов на всех 6 технологических пресетах.
- Целостность и наполненность всех 38 карточек первоисточников `RESEARCH_TOOLTIPS`.
- Работу алгоритма автобалансировки шихты до 100%.
- Сходимость и валидацию формул при граничных значениях.

### Локальный запуск сервера:
1. Откройте командную строку в папке проекта:
   ```bash
   cd PEK
   ```
2. Запустите встроенный HTTP-сервер Python:
   ```bash
   py -m http.server 8080
   ```
3. Откройте веб-браузер и перейдите по адресу:
   ```
   http://localhost:8080
   ```
